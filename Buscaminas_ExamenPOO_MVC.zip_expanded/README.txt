Buscaminas Examen POO - Version MVC

- Tablero 10x10
- 10 minas colocadas al azar
- Se puede marcar casillas (F)
- Comandos: 
  R A1  -> Revelar casilla A1
  M B3  -> Marcar o desmarcar B3
  G     -> Guardar partida
  X     -> Salir de la partida

Paquetes:
- examenpoo.modelo
- examenpoo.control
- examenpoo.vista
- examenpoo.excepciones
- examenpoo.persistencia

Hecho para el examen de Programacion Orientada a Objetos.
